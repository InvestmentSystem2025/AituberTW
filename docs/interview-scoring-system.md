# 面試評分系統使用指南

## 概述

面試評分系統是一個智能化的面試評估工具，能夠在面試過程中實時對面試者的回答進行評分，並在面試結束後提供詳細的分析報告。

## 核心功能

### 1. 五大評分維度

- **內容完整性** (0-10分，扣分制)
  - 答非所問：-2分
  - 回答不完整：-1分

- **邏輯清晰度** (0-10分，扣分制)
  - 條理不清：-2分
  - 邏輯錯誤：-2分

- **專業深度** (0-10分，加分制)
  - 正確回答專業問題：+2.5分
  - 展現深度理解：+1分

- **溝通表達** (0-10分，扣分制)
  - 表達不清晰：-2分
  - 表達不流暢：-2分

- **個人特質** (0-10分，加分制)
  - 向上心、求知慾：+2.5分
  - 持續學習：+2.5分
  - 活潑外向：+2.5分
  - 堅強抗壓：+2.5分

### 2. 合格標準設定

面試開始前，可以設定各項評分維度的合格標準（0-10分）。面試者需要所有維度都達到或超過設定標準才算合格。

### 3. 實時評分顯示

- 每次回答後，系統會在控制台輸出詳細評分結果
- 在面試界面中實時顯示各項分數
- 提供扣分和加分的具體原因

### 4. 最終結果分析

面試結束後，系統會生成：
- 各項維度的平均分數
- 總平均分數
- 合格/不合格判定
- 優勢分析
- 需要改進的地方
- 具體建議

## 使用方法

### 1. 設定評分標準

1. 在面試界面點擊「評分設定」按鈕
2. 調整各項評分維度的合格標準
3. 點擊「保存設定」

### 2. 開始面試

1. 系統會自動開始面試流程
2. AI面試官會根據設定的評分標準進行評分
3. 每次回答後，控制台會顯示評分結果

### 3. 查看結果

面試結束後，系統會自動跳轉到結果頁面，顯示：
- 評分總覽
- 詳細的問答記錄和評分
- 總結和建議

```
src/
├── types/
│   └── interviewScoring.ts          # 評分系統類型定義
├── features/
│   ├── interview/
│   │   ├── interviewScoring.ts      # 評分引擎核心邏輯
│   │   └── testScoring.ts          # 測試腳本
│   └── chat/
│       ├── interviewPromptTemplates.ts  # 更新後的提示詞模板
│       └── interviewAIChat.ts      # 更新後的AI聊天功能
└── components/
    └── interview/
        ├── InterviewScoringSettings.tsx  # 評分設定組件
        ├── InterviewInterface.tsx       # 更新後的面試界面
        └── InterviewResults.tsx         # 更新後的結果頁面
```

### 核心類別

- `InterviewScoringEngine`: 評分引擎，負責計算分數和生成結果
- `ScoringCriteria`: 評分標準介面
- `AnswerScore`: 單次回答評分結果
- `InterviewResult`: 最終面試結果

## 評分邏輯說明

### AI評分機制

AI面試官會在每次回應中隱藏評分信息，格式如下：

```
[SCORE_START]{"questionId":"q1","questionText":"問題","answerText":"回答","scores":{"contentCompleteness":8,"logicalClarity":7,"professionalDepth":6,"communicationSkills":8,"personalTraits":7},"totalScore":7.2,"deductions":["扣分原因"],"additions":["加分原因"],"aiFeedback":"AI回饋"}[SCORE_END]
```

### 評分判斷規則

系統會根據以下關鍵詞和模式進行評分：

- **內容完整性**: 檢查回答是否包含問題相關的關鍵詞
- **邏輯清晰度**: 檢查是否有邏輯連接詞和條理性
- **專業深度**: 檢查是否包含專業術語和深度分析
- **溝通表達**: 檢查表達的清晰度和流暢度
- **個人特質**: 檢查是否展現積極的個人特質

## 注意事項

1. **執行環境**: 所有指令都必須在 VSCode PowerShell 終端執行
2. **評分準確性**: 評分系統基於關鍵詞匹配，可能無法完全準確評估所有情況
3. **自定義調整**: 可以根據實際需求調整評分規則和權重
4. **數據保存**: 評分結果會保存在瀏覽器的內存中，刷新頁面會丟失
