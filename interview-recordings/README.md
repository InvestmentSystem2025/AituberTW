# 面試錄製視頻資料夾

此資料夾用於存放所有面試錄製的視頻檔案。

## 📁 檔案命名格式

```
interview_recording_YYYY-MM-DDTHH-MM-SS-SSSZ.mp4
```

例如：
- `interview_recording_2025-10-01T14-30-00-000Z.mp4`
- `interview_recording_2025-10-01T16-45-23-456Z.mp4`

## 🎥 錄製功能說明

### 開啟錄製
1. 在面試開始前，點擊「面試設置」
2. 啟用「🎥 錄製面試過程」選項
3. 開始面試後會自動開始錄製

### 錄製內容
- 面試者的視頻畫面（左側）
- AI 面試官的模型畫面（右側）
- 對話記錄介面（中間）
- 整個面試過程的音頻和畫面

### 檔案格式
- **格式**: MP4 (H.264 視頻編碼，AAC 音頻編碼)
- **解析度**: 1920x1080 或原始螢幕解析度
- **幀率**: 30 FPS
- **位元率**: 視頻 2500 kbps，音頻 128 kbps

## 📊 檔案大小估算

一般 30 分鐘的面試錄製：
- 預估檔案大小：約 500-800 MB
- 實際大小取決於畫面複雜度和面試時長

## 🗄️ 儲存位置

錄製檔案僅保存在本地：
```
c:\dev\AITUBER\aituber-kit\interview-recordings\
```

## 🔒 隱私提醒

面試錄製包含面試者的影像和語音，請妥善保管：
- ✅ 定期備份重要錄製
- ✅ 避免未授權訪問
- ✅ 依照隱私政策處理錄製檔案
- ❌ 不要將錄製檔案上傳到公開位置

## 💡 使用建議

1. **儲存空間**: 確保有足夠的儲存空間（建議至少 10 GB 可用空間）
2. **效能考量**: 錄製會佔用一些系統資源，建議在效能較好的電腦上使用
3. **定期清理**: 定期清理不需要的錄製檔案，釋放儲存空間
